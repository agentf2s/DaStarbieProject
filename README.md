*So why am I doing this?*
I participated in a 10 week challenge to build hardware and this is one of the starter projects. I wasn't sure what exactly I wanted to build so I went for the starter project. I'm required to have a repo containing everything so this is it.

*What is it?*
A tamagotchi style thing that responds to the way you move and the buttons you click.
It's super duper cool.

*How*

Use the PCB Designs uploaded and get them printed, and use arduino IDE to upload the firmware to the esp32. Should be simple enough.
